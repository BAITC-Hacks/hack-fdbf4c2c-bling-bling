# Сервисы обработки

`audio.py` сохраняет загрузку локально и вызывает настоящий ffmpeg для подготовки
WAV PCM 16-bit, mono, 16 kHz. Доступны ограничения размера, длительности и таймаут.
`transcription.py` определяет интерфейс `TranscriptionService` и локальный
`FasterWhisperTranscriptionService`. Он загружает заранее подготовленную модель,
сохраняет исходный язык текста и возвращает типизированные сегменты/слова с временем.
API атомарно сохраняет результат в `data/processed/{meeting_id}/transcript_raw.json`.
`diarization.py` содержит локальный адаптер Community-1; исходные метки голосов
не являются биометрической идентификацией. `extraction.py` содержит
`ActionItemExtractionService` и проверку доказательств. `local_llm.py` задает
интерфейс локальной модели; `ollama.py` реализует транспорт независимо от анализа.
`summarization.py` реализует `MeetingSummaryService` через тот же LocalLLMClient.
Обе инструкции читаются из `app/prompts/*.txt`. Основные поручения summary
копируются из проверенного результата извлечения без изменения сроков/исполнителей.
На следующих этапах здесь появятся alignment и export.
При недоступных моделях тестовые адаптеры будут явно обозначаться как mock.
Статус `audio_ready` означает только подготовку аудио, а не выполнение AI pipeline.
`transcribed` означает только завершение STT; остальные стадии имеют отдельные статусы.
