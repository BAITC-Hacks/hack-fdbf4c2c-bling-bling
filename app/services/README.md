# Сервисы обработки

На этапе 1 сервисы обработки не реализованы и не вызываются API.
На следующих этапах здесь появятся audio, transcription, diarization,
alignment, extraction, summarization и export с адаптерами локальных моделей.
При недоступных моделях тестовые адаптеры будут явно обозначаться как mock.
Статус `created` не означает запуск обработки.
