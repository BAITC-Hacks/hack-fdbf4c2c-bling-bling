# Этап 4: проверка Speech-to-Text

Дата: 23 сентября 2026. Прогон выполнен локально на CPU, около 8 ГБ RAM,
AMD Radeon без обнаруженной NVIDIA CUDA. Адаптер: faster-whisper 1.2.1,
CTranslate2 4.8.2, модель `small`, compute type `int8`, 4 потока.
Модель `large-v3` остается default конфигурации, но на этом компьютере не проверялась.

## Реальные аудиопримеры

Источник — [Google FLEURS](https://huggingface.co/datasets/google/fleurs),
лицензия CC BY 4.0. Использованы первые записи validation для `ru_ru` и `kk_kz`.
Смешанный пример создан последовательным соединением RU и KZ с паузами по 0,5 с.
Это моделирование смены языка между репликами; **естественное смешение внутри
предложения не проверено**. Одна запись на язык не является репрезентативным benchmark.
Данные встречи пользователя никуда не передавались.

Файлы, исходные тексты и результаты находятся локально в `data/stt-evaluation/`
и исключены из Git. Русский пример получен через dataset viewer; казахский —
из первого ряда `kk_kz/validation/0000.parquet` ветки `refs/convert/parquet`
после ошибки лимита размера viewer. WAV подготовлены локальным ffmpeg.
Скрипт подготовки и `manifest.json` оставлены рядом с локальными данными.

| Пример | Аудио, с | STT при окне 30 с, с | WER, окно 30 с | WER, окно 10 с |
| --- | ---: | ---: | ---: | ---: |
| Русский | 13,68 | 12,49 | 7,7% | 11,5% |
| Казахский | 12,30 | 12,30 | 46,7% | 66,7% |
| Склеенные RU/KZ | 26,98 | 19,80 | 46,3% | 46,3% |

Время первого вызова включает загрузку модели. Другие параметры одинаковы:
`task=transcribe`, `language=None`, `multilingual=True`, `word_timestamps=True`,
`vad_filter=True`, `condition_on_previous_text=False`, `beam_size=5`.
WER вычисляется после приведения к нижнему регистру и разделения по Unicode-словам,
без пунктуации. Вставки, удаления и замены делятся на количество слов эталона;
метрика может превышать 100%. В ТЗ нет установленного порога WER.

## Выводы из результатов

- На отдельных записях язык определился как `ru` и `kk`. Выданы реальные метки слов
  и сегментов. Текст не переводится постобработкой, task всегда `transcribe`.
- `detected_language` для смешанного файла — `ru`: это первичное определение,
  не утверждение, что весь файл русскоязычный. Поэтому в JSON есть
  `language_scope=initial_detection`.
- При стандартном окне 30 с модель small пропустила казахскую часть смешанной
  записи. Окно 10 с дало фрагмент с искажениями и не улучшило WER; на отдельных
  языках стало хуже. Defaults не менялись на основании одного неудачного эксперимента.
- Требования к качественному пониманию казахского и смешанной речи **не закрыты**.
  Нужны дополнительные естественные записи и сравнение с large-v3/другой
  совместимой многоязычной моделью на подходящем оборудовании.
- CUDA проверена только тестовыми doubles выбора устройства. Реального GPU-прогона нет.
- Во время оценки блокировались Python socket.connect. Модель загружалась из локального
  каталога. Это проверка отсутствия необходимости сети в данном прогоне, не аудит
  системного firewall или нативных библиотек.

## Особенности multilingual

Проверен исходный код установленной версии 1.2.1: обычный `WhisperModel.transcribe`
при multilingual переопределяет язык для каждого окна encoder. Выходные сегменты
могут иметь другие границы; гарантии определения языка для каждого слова нет.
Вызов остается transcription. BatchedInferencePipeline не используется.
[Исходный код версии](https://github.com/SYSTRAN/faster-whisper/blob/v1.2.1/faster_whisper/transcribe.py).

## Воспроизведение

Дополнительно пройден сквозной API-прогон на русском примере. Файл результата:
`data/processed/6cb32930-5fb9-486f-bafc-044839bc88d6/transcript_raw.json`.
Это реальный результат модели small, а не test double; он исключен из Git.
Все 53 автотеста прошли; живой HTTP `/health` — 200, сервер штатно остановлен.

После подготовки разрешенных WAV и manifest:

```powershell
$env:WHISPER_MODEL = 'small'
$env:WHISPER_DEVICE = 'cpu'
$env:WHISPER_COMPUTE_TYPE = 'int8'
.venv/Scripts/python.exe scripts/prepare_whisper.py
.venv/Scripts/python.exe scripts/evaluate_stt.py data/stt-evaluation/manifest.json
$env:WHISPER_CHUNK_LENGTH = '10'
.venv/Scripts/python.exe scripts/evaluate_stt.py data/stt-evaluation/manifest.json --output data/stt-evaluation/report_chunk10.json
```

Подготовка весов использует сеть; `evaluate_stt.py` — только локальные файлы.
Не подставляйте тестовые transcripts в модель: эталоны используются исключительно
для расчета WER после распознавания.
