# План реализации и приёмка

## Этапы

| Этап | Работа | Условие завершения |
| --- | --- | --- |
| 1. Данные и контракты | Сверить MP3 с текстами, разметить эталон, определить схемы и правила сроков | Есть проверенные примеры, дата/часовой пояс заданы явно либо отмечены неизвестными |
| 2. Вертикальный прототип | Загрузка, локальная ASR, хранение результата, экран транскрипта | Одна запись проходит полный путь без внешнего API |
| 3. Говорящие и языки | Диаризация, сопоставление имён, русский/казахский/смешанный набор | Есть раздельный отчёт по языкам и говорящим |
| 4. Анализ текста | Поручения, уточнения, дедупликация, саммари, ручная проверка | Пройдены примеры из инструкции по извлечению |
| 5. Документы | PDF, DOCX, сохранение ревизий | Оба формата открываются и визуально проверены |
| 6. Сценарии и доставка | Напоминания, права доступа, удаление, офлайн-запуск, README | Команда воспроизводит демонстрацию по инструкции |
| 7. Дополнительные входы | Live-поток и адаптеры конференций | Каждый заявленный канал отдельно проверен; нереализованные явно обозначены |

## Набор проверки

Подготовить отдельные эталоны для аудио и для извлечения поручений. В тест модели передавать только реплики, без готового раздела саммари и таблиц поручений из Markdown: иначе результат будет измерять копирование ответа. Полный документ использовать для сверки разметки.

Разделить набор на разработку и итоговую проверку. Добавить казахский и смешанный материал: имеющиеся Markdown-примеры русскоязычные и не подтверждают покрытие остальных языков. Для синтетических примеров явно обозначить их происхождение.

| Проверка | Ожидаемый результат |
| --- | --- |
| Протокол №1 | Покрыты десять базовых действий, нет дублей после подытоживания, учтены уточнения сроков |
| Протокол №2 | Покрыты все действия, Ерлан определён исполнителем, срок сметы не перенесён на всё обучение |
| Неизвестная дата записи | Относительные сроки не превращены в даты от текущего дня |
| Нет поручений / только тишина | Пустой список, понятное состояние, нет выдуманных решений |
| Неизвестный исполнитель | Значение неизвестно, требуется проверка; говорящий не назначен автоматически |
| Смешанная речь и казахские имена | Смысл, имена и сроки проверены человеком, исходный язык сохранён |
| Повреждённый файл / нехватка памяти | Контролируемая ошибка без облачного переключения |
| Повтор запуска задания | Нет повторных поручений или уведомлений |
| Редактирование и экспорт | Правки сохранены, PDF и DOCX соответствуют одной ревизии |
| Повторный запуск планировщика | Нет дублей; завершённые задачи не получают напоминания |
| Чужое совещание | API, аудио и экспорт недоступны другому пользователю без прав |
| Удаление | Удалены связанные данные и временные файлы в пределах политики хранения |
| Отключённый интернет | Основной цикл обработки и экспорта работает полностью |

## Отчёт о качестве

Фиксировать версии кода/моделей, оборудование, длительность входа, время обработки и пиковую память. Для ASR указать WER/CER по каждому языку, для диаризации — DER с правилами расчёта. Для поручений считать precision/recall по ручной разметке, отдельно точность исполнителя и срока; правила сопоставления составных поручений определить до подсчёта.

Проверять неподтверждённые факты в саммари вручную по источникам. Численные пороги качества согласовать после базового прогона: ТЗ не содержит готовых порогов, поэтому не представлять проектные цели как требования организаторов. Не заявлять поддержку языка без соответствующего теста.

## Что показать на сдаче

Демонстрация: загрузить запись, показать смену говорящих, открыть доказательство поручения, исправить имя или срок, подтвердить результат, скачать оба формата и показать напоминание с тестовыми часами. Отдельно предъявить результат офлайн-проверки.

Обновить корневой README: архитектура, установка, подготовка локальных моделей, конфигурация, команды запуска, тестовые данные, основной сценарий и известные ограничения. Приложить отчёт о проверках. Это покрывает критерии ТЗ: работоспособность (25), техническая реализация (25), README и воспроизводимость (25), ценность (15), развитие и оригинальность (10).
