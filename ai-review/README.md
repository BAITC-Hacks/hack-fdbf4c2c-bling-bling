# Инструкции по реализации системы протоколирования

Эта папка описывает план разработки по материалам `docs/`. Это инструкции для команды, а не описание уже реализованного приложения. На момент анализа в репозитории есть README и материалы задачи; исходного кода и конфигурации запуска нет.

## Источники и приоритет

- [Техническое задание](../docs/HackAlem%20AI_%20Система%20автопротоколирования%20совещаний%20с%20фиксацией%20поручений.md) — источник требований и ограничений.
- [Протокол №1](../docs/Протокол_совещания№1.docx.md) — явные поручения, уточнение сроков и тематические разделы.
- [Протокол №2](../docs/Протокол_совещания№2.docx.md) — поручения из диалога, отсутствующие сроки и исполнители, которые не выступают.
- `docs/Совещание №1.mp3` и `docs/Совещание №2.mp3` — входные аудиоматериалы. При подготовке этих инструкций аудио не прослушивалось; соответствие текста записям необходимо проверить перед оценкой качества.

При расхождении примера и ТЗ следовать ТЗ. При расхождении саммари и реплик сохранять доказательства из реплик и показывать спорное место пользователю. Предложения по архитектуре и критерии качества ниже являются проектными решениями, а не дополнительными условиями организаторов.

## Основной результат

Секретарь загружает запись, задаёт дату, часовой пояс и участников, получает транскрипт с говорящими, проверяет автоматически выделенные поручения и скачивает протокол. Аудио и текст обрабатываются внутри локального контура. Русский, казахский и смешанная речь проверяются раздельно.
